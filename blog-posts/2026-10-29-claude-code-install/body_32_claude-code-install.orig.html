這一篇要裝什麼：先訂 Pro，再挑一種裝法

Claude Code 要付費方案才能用，Claude 免費版不含 Claude Code。訂好方案後，三種裝法挑一種就好：

  • 桌面版：沒用過程式工具的人選這個，全程不用打指令。
  • VS Code 擴充套件：想邊做邊看程式碼的人選這個。
  • 終端機一行指令：想在終端機輸入 claude 直接用的人選這個。

Windows 和 Mac 都能裝。電腦要 Windows 10（1809 版）以上或 macOS 13 以上，記憶體 4 GB 以上。Claude Code 官方安裝說明

安裝中途卡住，把這篇文章的連結和畫面上的完整錯誤訊息一起貼給 AI：

https://aixwang.dev/blog/claude-code-install/

錯誤訊息請貼原文，不要只說「安裝失敗」，AI 才能對照本文判斷你卡在哪一步。

第一步：訂閱 Claude Pro

到 Claude 官方價格頁，選紅框標示的 Pro。發文當下月繳 20 美元，年繳平均每月 17 美元（一次付 200 美元）。用量不夠時再升級 Max，Team、Enterprise 方案也能用 Claude Code。

第二步：安裝 Claude Code（三選一）

桌面版：不用終端機

  1. 到 Claude 下載頁，Windows 按紅框標示那一列的 Download；Mac 按 macOS 那一列。Windows 筆電是 ARM 處理器的，改按 Windows (arm 64)。
  2. 執行下載的安裝檔。Windows 從開始選單、Mac 從「應用程式」資料夾開啟 Claude，登入你剛訂閱的帳號。
  3. 點側邊欄上方的 Code 分頁。跳出升級提示，代表這個帳號還沒有付費方案。
  4. 在輸入框下方的環境選單選 Local 底下第一個，再按旁邊的資料夾按鈕，選 Open folder… 開啟你的專案資料夾。

桌面版已經包含 Claude Code，不用另外裝 Node.js 或終端機版。想在終端機輸入 claude，要再照下面的終端機裝法裝一次。官方桌面版說明

VS Code 擴充套件

VS Code 要 1.94.0 以上，還沒裝 VS Code 的話，先照 Codex 安裝教學（上）的第一步裝好。

  1. 在 VS Code 按 Ctrl + Shift + X（Mac 為 Cmd + Shift + X）打開擴充套件，搜尋 Claude Code。
  2. 確認名稱是 Claude Code for VS Code、發行者是 Anthropic 而且有藍色驗證勾勾，再按 Install。先確認發行者，才不會裝到別人做的套件。
  3. 點左側活動列的 Claude Code 圖示打開面板，按 Sign in，在瀏覽器完成授權。

擴充套件自己帶一份 Claude Code，只給聊天面板用。想在 VS Code 的終端機輸入 claude，一樣要另外照下面的終端機裝法裝。官方 VS Code 說明

終端機一行指令

Windows 開 Windows PowerShell（不要選後面有 x86 的那個），貼上：

irm https://claude.ai/install.ps1 | iex

習慣用命令提示字元（CMD）的話，改貼這行：

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Mac 開「終端機」App，貼上：

curl -fsSL https://claude.ai/install.sh | bash

不用系統管理員權限。下載時畫面不會顯示進度，等它跑完就好。這種裝法會在背景自動更新，之後不用自己升級。

裝完關掉視窗、開一個新的終端機，輸入：

claude --version

看到版本號就是裝好了，例如：

2.1.312 (Claude Code)

出現「找不到 claude」之類的訊息，看文末的錯誤排除。

第三步：在專案資料夾啟動並登入

桌面版和 VS Code 擴充套件在上一步已經登入，可以跳過這一步。

終端機版要先進到專案資料夾再啟動，Claude Code 才讀得到你的檔案。資料夾名稱換成你自己的：

cd 你的專案資料夾
claude

第一次啟動會自動開瀏覽器，用訂閱 Pro 的帳號登入、按授權，回到終端機就能開始輸入需求。

  • 瀏覽器沒有自己打開：在終端機按 c 複製登入網址，貼到瀏覽器。
  • 瀏覽器顯示一串登入碼、沒有跳回來：把登入碼貼回終端機 Paste code here if prompted 的地方。在 WSL 裡登入常遇到這種情況。

之後要換帳號，在 Claude Code 裡輸入：

/login

官方登入說明

選用：Windows 裝 Git for Windows

官方建議 Windows 裝 Git for Windows，但不是必要。裝了，Claude Code 能用 Git Bash 執行指令，有些功能要靠它；沒裝，它改用 PowerShell 執行指令。Mac 不用裝。

Windows 想用 Linux 環境開發，可以改在 WSL 裡用終端機裝法安裝，WSL 的裝法看 Codex 安裝教學（下）：Windows 版 Codex CLI 與 WSL2 進階安裝，在 WSL 裡就不需要 Git for Windows。

安裝卡住怎麼辦？

先對照下面的錯誤訊息。都不是的話，在終端機輸入 claude doctor，它會檢查安裝和設定、列出問題與建議的修法，把結果整段貼給 AI。官方安裝問題排除

'claude' is not recognized／command not found: claude

Claude Code 裝好了，但安裝位置不在系統的 PATH 裡，終端機找不到它。先確認有沒有開新的終端機視窗。還是不行，Windows 在 PowerShell 依序貼上這兩行：

$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

關掉終端機重開，再輸入 claude --version。

'irm' is not recognized／The token '&&' is not a valid statement separator

指令貼錯視窗了。看到 'irm' is not recognized，代表你在命令提示字元（CMD），請改開 PowerShell 貼 irm 那行，或改貼 CMD 用的那行。看到 The token '&&'，代表你在 PowerShell 貼了 CMD 用的指令，改貼 irm 那行。

Claude Code does not support 32-bit Windows

開始選單裡有 Windows PowerShell 和 Windows PowerShell (x86) 兩個，你開到 x86 那個了。即使電腦是 64 位元，x86 版也會出現這個錯誤。關掉它，改開沒有 x86 的 Windows PowerShell，再貼一次安裝指令。

輸入 claude 打開的是桌面版

舊版的 Claude 桌面版會搶走 claude 這個指令。把桌面版更新到最新版就會恢復。

啟動時問要不要用 API Key

你的電腦設過 ANTHROPIC_API_KEY 這個環境變數，Claude Code 會問你要不要用這把 Key。要用 Pro 訂閱，就不要同意，或先把這個環境變數刪掉，再重新啟動 claude 登入。
