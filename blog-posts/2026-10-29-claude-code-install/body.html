三種裝法怎麼選

Claude Code 要 Pro 以上的付費方案才能用，Claude 免費版不含。三種裝法挑一種就好，看你平常怎麼工作：

  • 不想打指令：選桌面版，全程不用打指令。
  • 平常用 VS Code：選 VS Code 外掛（介面上叫「擴充功能」，英文是 extension），邊做邊看程式碼。
  • 習慣在終端機工作：選 CLI（終端機畫面），裝好直接輸入 claude。

Windows 和 Mac 都能裝。電腦要 Windows 10（1809 版）以上或 macOS 13 以上，記憶體 4 GB 以上。Claude Code 官方安裝說明

安裝中途卡住，看文末安裝卡住怎麼辦。

第一步：訂閱 Claude Pro

到 Claude 官方價格頁，選紅框標示的 Pro，訂閱時選月繳，每月 20 美元。AI 工具汰換率很高，隨時會出現更好用的，月繳才不會被綁住。用量不夠時再升級 Max，Team、Enterprise 方案也能用 Claude Code。

第二步：安裝 Claude Code（三選一）

桌面版

  1. 到 Claude 下載頁，選擇適合你的作業系統，按 Download。
  2. 執行下載的安裝檔。Windows 從開始選單、Mac 從「應用程式」資料夾開啟 Claude，登入你剛訂閱的帳號。
  3. 點側邊欄上方的 Code 分頁。跳出升級提示，代表這個帳號還沒有付費方案。
  4. 在輸入框下方的環境選單選 Local 底下第一個，再按旁邊的資料夾按鈕，選 Open folder… 開啟你的專案資料夾。

桌面版已經包含 Claude Code，不用另外裝 Node.js 或 CLI 版。想在終端機輸入 claude，要再照下面的 CLI 裝法裝一次。官方桌面版說明

VS Code 外掛

VS Code 要 1.94.0 以上。還沒裝的話，先裝好：

[[snippet:vscode-install]]

VS Code 準備好之後，安裝 Claude Code 外掛：

  1. 在 VS Code 按 Ctrl + Shift + X（Mac 為 Cmd + Shift + X）打開擴充功能（Extensions）面板，搜尋 Claude Code。
  2. 確認名稱是 Claude Code for VS Code、發行者是 Anthropic 而且有藍色驗證勾勾，再按 Install。先確認發行者，才不會裝到別人做的套件。
  3. 點左側活動列的 Claude Code 圖示打開面板，按 Sign in，在瀏覽器完成授權。

外掛自己帶一份 Claude Code，只給聊天面板用。想在 VS Code 的終端機輸入 claude，一樣要另外照下面的 CLI 裝法裝。官方 VS Code 說明

CLI（終端機畫面）

Windows 開 Windows PowerShell（不要選後面有 x86 的那個），貼上：

irm https://claude.ai/install.ps1 | iex

習慣用命令提示字元（CMD）的話，改貼這行：

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Mac 開「終端機」App，貼上：

curl -fsSL https://claude.ai/install.sh | bash

不用系統管理員權限。下載時畫面不會顯示進度，等它跑完就好。這種裝法會在背景自動更新，之後不用自己升級。

裝完關掉視窗、開一個新的終端機，輸入：

claude --version

看到版本號就是裝好了，例如：

2.1.312 (Claude Code)

出現「找不到 claude」之類的訊息，照文末安裝卡住怎麼辦，把錯誤貼給 AI。

第三步：啟動並登入

桌面版和 VS Code 外掛在上一步已經登入，可以跳過這一步。

CLI 版要先進到專案資料夾再啟動，Claude Code 才讀得到你的檔案。資料夾名稱換成你自己的：

cd 你的專案資料夾
claude

第一次啟動會自動開瀏覽器，用訂閱 Pro 的帳號登入、按授權，回到終端機就能開始輸入需求。

  • 瀏覽器沒有自己打開：在終端機按 c 複製登入網址，貼到瀏覽器。
  • 瀏覽器顯示一串登入碼、沒有跳回來：把登入碼貼回終端機 Paste code here if prompted 的地方。在 WSL 裡登入常遇到這種情況。

之後要換帳號，在 Claude Code 裡輸入：

/login

官方登入說明

選用：Git for Windows

官方建議 Windows 裝 Git for Windows，但不是必要。裝了，Claude Code 能用 Git Bash 執行指令，有些功能要靠它；沒裝，它改用 PowerShell 執行指令。Mac 不用裝。

Windows 想用 Linux 環境開發，可以改在 WSL 裡用 CLI 裝法安裝，WSL 的裝法看 Codex 安裝教學（下）：Windows 版 Codex CLI 與 WSL2 進階安裝，在 WSL 裡就不需要 Git for Windows。

安裝卡住怎麼辦？

把錯誤訊息貼給 Claude 或 ChatGPT 這類 AI，請它幫你看。複製下面這段，括號裡的換成你的情況：

我在安裝 Claude Code 時卡住了，請幫我排除。
安裝教學：https://aixwang.dev/blog/claude-code-install/
作業系統：（Windows 10、Windows 11 或 macOS）
安裝方式：（桌面版、VS Code 外掛或 CLI）
做到哪一步：（寫你卡在哪裡）
（在這裡貼上完整錯誤訊息）

錯誤訊息要貼完整原文，不要只寫「安裝失敗」。在終端機或安裝視窗選取整段文字複製；複製不了就截圖整個視窗，連同這段提示詞一起傳給 AI。

看不出原因，就在終端機輸入 claude doctor，它會檢查安裝和設定、列出問題與建議的修法，把結果整段一起貼給 AI。官方安裝問題排除
