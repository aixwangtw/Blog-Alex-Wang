<h3 id="module-02threads-api-申請與-token-設定">Module 02：Threads API 申請與 Token 設定</h3>
<p>Threads 的申請跟 FB / IG 不太一樣：FB 跟 IG 可以透過企業管理後台新增資產管理取得永久權限的 Token，Threads 則要走開發者後台申請、長期 Token 60 天需延期。這個模組帶你完整跑一次 Threads 申請與 Token 設定。</p>
