先點選左側紅框標示的擴充功能（Extensions）圖示（快捷鍵：Windows Ctrl + Shift + X、Mac Cmd + Shift + X），再搜尋 Codex。搜尋結果可能不只一個，請選擇同時符合以下三個特徵的官方外掛：

  • 使用 OpenAI 的黑白 Logo；
  • 外掛名稱下方的公司名稱是 OpenAI；
  • 公司名稱旁有藍色驗證勾勾。

確認三項都符合後，再按藍色 Install 按鈕。不要只因為名稱包含 Codex 就直接安裝，以免裝到仿冒或非 OpenAI 官方發布的外掛。

先確認右側面板目前選到的是 Codex。VS Code 的預設 AI 通常是 Chat（GitHub Copilot）；安裝 Codex 後，點開聊天面板上方的 AI 選擇器，將 Chat／Copilot 切換成 Codex。
