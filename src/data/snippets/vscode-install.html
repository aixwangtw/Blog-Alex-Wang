前往 VS Code 官方網站，下載你的作業系統對應的版本：

  • Windows：執行下載的安裝檔，依照安裝精靈完成安裝。安裝程式會把 VS Code 加進 PATH，裝完重開終端機，在資料夾裡輸入 code .，就能用 VS Code 開啟那個資料夾。官方 Windows 安裝說明
  • Mac：打開下載的 .dmg 檔，把 Visual Studio Code 拖進「應用程式（Applications）」資料夾，再從該資料夾開啟。官方 Mac 安裝說明

想把介面改成繁體中文：

  1. 按 Ctrl + Shift + P（Mac 為 Cmd + Shift + P）。
  2. 輸入並選擇 Configure Display Language。
  3. 選擇「中文（繁體）」或 zh-tw；還沒裝語言包，VS Code 會自動安裝。
  4. 依照畫面提示重新啟動 VS Code。VS Code 官方說明
