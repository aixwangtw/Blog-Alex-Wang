**零基礎學 AI，不需要先背 Prompt 或學 Python。先把 Codex 裝好，接著學會安裝 Skills 與開源工具，直接使用前輩已經整理好的工作流。** 你不用每件事都從空白開始，也能更快看到 AI 真正幫你完成任務。

## 從「零散技巧」到「真實作品」

會來找我上課的學員，很多已經在網頁版問過問題，也看過不少 Prompt 技巧，但始終停在「問答」。真正的分水嶺，是把 Codex 這類 AI Agent 裝到電腦上，讓它能讀取專案、修改檔案、執行指令，再由你確認每一步結果。

所以入門重點不是一次學完所有 AI 工具，也不是從零發明自己的流程。先安裝別人驗證過的 Skill 或開源工具，照著既有工作流跑完一次，再從使用過程學會權限、測試、驗收與除錯，會比只看觀念快很多。

## 我建議的四步學習路線

這也是我帶新手實作時採用的順序。自學者可以直接照著走：

1. **先安裝 Codex**：Windows 新手先用 [VS Code＋Codex 插件版](/blog/codex-windows-wsl-install/)，完成登入、開啟專案資料夾與第一次對話。日常使用夠了，不必一開始就裝 WSL2。
2. **學會安裝 Skills 與開源工具**：Skills 是前輩整理好的工作流程，開源工具則是已經做好的成品。到[免費資源頁](/resources/)複製安裝指令，交給 Codex 協助安裝，不用從空白 Prompt 或空白專案開始。
3. **直接使用現成工作流**：先照原本的用法跑通，再練習替換自己的文字、圖片或資料。使用時仍要自己打開成果驗收，不要只看 AI 說「完成了」。
4. **延伸成自己的真實作品**：熟悉現成流程後，再改成你真的會使用的成果。想做社群自動化，可跟著 [Threads API 教學](/blog/threads-api-tutorial/)發出第一篇貼文；想做社群圖文，可使用開源工具 [Tooka](/blog/why-i-built-tooka/)；沒有這些需求，也可以延伸成自己的網站或日常工作流程。

走完這四步，你會同時練到安裝、任務拆解、權限、驗收與除錯。之後想做 AI 客服、AI 自動拍片或其他自動化，都是同一套邏輯的延伸。

## 免費資源怎麼搭配這篇使用？

這篇負責回答「先學什麼、順序怎麼排」；[免費資源頁](/resources/)則放可以直接交給 Agent 安裝的 Skills、開源工具、Codex 安裝教學與 API 影片。裝好 Agent 後就到免費資源頁挑一項開始，直接使用前輩整理好的工作流，不需要全部看完才動手。

## 自學卡關了怎麼辦？

先從[免費資源](/resources/)開始，自學能力強的人可以直接照做。如果你卡在環境設定或 Meta 後台，或想用自己的帳號完成一個真實作品，可以約我的[一對一私人教學](/services/ai-tutor/)——雙北實體或線上皆可。
